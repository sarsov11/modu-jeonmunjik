# 틀린 기출 문장 해설 쓰기 — 공통 지시 (2026-10-13)

모두의 전문직 앱에서 학생이 O·X 를 풀고 나면 해설이 나온다. 지금은 「정답은 X」만 나오고 왜 틀렸는지가 없다. 틀린(X) 기출 문장마다 해설을 쓴다.

## 지켜야 할 것
- 창을 띄우지 않는다. 브라우저·start·explorer·webbrowser 금지. 파이썬 subprocess 는 CREATE_NO_WINDOW.
- 한국어 글은 `C:\Users\UserK\.claude\규칙\한국어_AI말투_금지.md` 를 먼저 읽고 지킨다. 다 쓴 뒤 표본 30개를 직접 읽어 고친다.
- **스크립트로 해설을 자동 생성하지 않는다.** 문장을 하나씩 직접 읽고 쓴다. 파이썬은 파일 읽기·쓰기·검사에만 쓴다.
- 「헷갈리는 짝」「되돌리기」「헷갈리는 자리」「맞는 문장 읽기」라는 말은 쓰지 않는다.

## 입력
`C:\Users\UserK\Desktop\모두의전문직\앱\data\<과목id>.js` 안의 `window.QBANK=`(쟁점번호 → 문장 목록. i=문장 id, t=문장, ox=O/X, y=연도, e=시험, tp=문항 주제)와 `window.PAIRS=`(o=맞는 문장, x=틀린 문장). 각 `window.X=` 뒤부터 다음 `;\nwindow.` 앞까지 json.loads.
- 같은 쟁점의 O 문장과 PAIRS 의 o 쪽이 정답 근거로 가장 믿을 만하다. 먼저 그것과 맞춰 본다.

## 할 일
ox 가 "X" 인 문장마다:
- `f`: 맞게 고친 문장. 원문에서 틀린 부분만 바꾼다(나머지 낱말은 그대로). 주어·서술어가 맞게.
- `w`: 왜 틀렸는지 1~2문장. 바른 사실(숫자·기간·주체·요건·예외·판례 결론)을 그냥 말한다. 근거 조문(「근로기준법 제23조」처럼)이나 판례 결론을 확실할 때만 붙인다. 「~을 ~로 바꾼 진술이다」 같은 이름표 말투 금지.
- `c`: 확신도 "상"(조문·판례로 확실) / "중"(정답은 확실, 근거 세부는 덜 확실) / "하"(왜 틀렸는지 확신이 없음). 하는 따로 목록에 보고한다.
- 2026년 현행 법령 기준. 출제 뒤 법이 바뀌어 지금은 맞는 문장이 된 경우 w 에 「(20XX 개정 전 기준 X. 현행은 …)」로 적는다.
- 「모두 고른 것」·사례형 문장처럼 원문 자체가 조각이면 f 는 비워 두고("") w 만 쓴다.

## 출력
`C:\Users\UserK\Desktop\모두의전문직\앱\data\expl\<과목id>.json` — UTF-8, ensure_ascii=False:
{"<문장 id>": {"f": "...", "w": "...", "c": "상"}, ...}
중간에 끊겨도 이어 쓸 수 있게 50개마다 저장한다(이미 있는 id 는 건너뛴다).

## 끝나면
파이썬으로 검사: X 문장 id 가 전부 있는지, w 가 비지 않았는지, f 가 원문과 같지 않은지(f 가 있는 경우). 보고는 짧게: 개수, 확신도 하 목록(id·이유), 개정 반영 목록.
