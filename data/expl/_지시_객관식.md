# 객관식 기출 해설 쓰기 — 공통 지시 (2026-10-13)

O·X 로 쪼개지 못한 객관식 기출(계산·사례·「모두 고른 것」·영어 독해)에 해설을 쓴다. 지금 앱은 「정답 ③」만 보여 준다.

## 지켜야 할 것
- 창을 띄우지 않는다. 브라우저·start·explorer·webbrowser 금지. 파이썬 subprocess 는 CREATE_NO_WINDOW.
- 한국어 글은 `C:\Users\UserK\.claude\규칙\한국어_AI말투_금지.md` 를 먼저 읽고 지킨다.
- **스크립트로 해설을 자동 생성하지 않는다.** 문항을 하나씩 직접 읽고 푼다. 계산 문항은 파이썬으로 검산해도 된다(검산만).
- 「헷갈리는 짝」「되돌리기」「헷갈리는 자리」「맞는 문장 읽기」라는 말은 쓰지 않는다.

## 입력
`C:\Users\UserK\Desktop\모두의전문직\앱\data\<과목id>.js` 의 `window.QBANK=`(json). 문항 중 `mc` 가 있는 것: mc.s=발문, mc.d=자료(보기 ㄱㄴㄷ·표·지문), mc.o=선지 배열, mc.a=정답 번호(1부터). 문항 id 는 바깥 `i`.

## 할 일
`mc` 문항마다 `w` 한 덩어리를 쓴다(앱이 「해설」 아래 그대로 보여 준다. 줄바꿈 \n 가능):
- 첫 줄: 정답 근거 — 계산이면 풀이식과 값(단계 2~5줄), 「모두 고른 것」이면 ㄱ·ㄴ·ㄷ·ㄹ 각각 O/X 와 한 줄 이유, 법 문항이면 근거 조문·판례 결론, 영어 독해면 근거 문장과 뜻.
- 정답이 데이터의 mc.a 와 다르다고 판단되면 고치지 말고 `c` 를 "의심"으로 두고 보고한다.
- 바른 사실을 그냥 말한다. 「~을 ~로 바꾼 진술」 같은 이름표 말투, 훈계, 예고 문장 금지.
- `c`: "상" / "중" / "하" / "의심".

## 출력
`앱\data\expl\<과목id>_mc.json` (X 문장 해설 파일과 따로 — 동시에 쓰다 지우지 않게). UTF-8, ensure_ascii=False.
형식: {"<문항 id>": {"w": "...", "c": "상"}}. 50개마다 저장하고, 이미 있는 id 는 건너뛴다.

## 끝나면
mc 문항 id 가 전부 있는지 검사. 보고: 개수, 「의심」 목록(id·이유), 「하」 목록. 짧게.
